# Textarea

A multi-line text input component with support for auto-growing height, character count display, helper text, and inline error messages. Available in default and filled style variants, with animated error transitions powered by Framer Motion.

## Import

```tsx
import { Textarea } from '@wavebooking/aqua-fusion';
```

## Preview

<StorybookEmbed story="components-textarea--default" height={250} />

## Usage

```tsx
<Textarea placeholder="Write your message..." />

<Textarea
  label="Bio"
  variant="filled"
  size="lg"
  maxLength={500}
  showCount
  placeholder="Tell us about yourself..."
/>

<Textarea
  label="Description"
  error="Description is required"
  helperText="Maximum 200 characters"
  maxLength={200}
  showCount
  autoGrow
/>
```

## Props

<PropsTable props={[
  { name: 'label', type: 'string', description: 'Label text displayed above the textarea.' },
  { name: 'variant', type: "'default' | 'filled'", default: "'default'", description: 'Visual style variant. Filled uses a muted background with no border.' },

  { name: 'showCount', type: 'boolean', default: 'false', description: 'Whether to display a character count. Requires maxLength to be set.' },
  { name: 'autoGrow', type: 'boolean', default: 'false', description: 'Whether the textarea automatically grows in height as content is typed.' },
  { name: 'maxRows', type: 'number', default: '10', description: 'Maximum number of rows when autoGrow is enabled.' },
  { name: 'maxLength', type: 'number', description: 'Maximum number of characters allowed. Used with showCount for the counter display.' },
  { name: 'value', type: 'string', description: 'Controlled value of the textarea.' },
  { name: 'defaultValue', type: 'string', description: 'Default value for uncontrolled usage.' },
  { name: 'onChange', type: '(e: ChangeEvent<HTMLTextAreaElement>) => void', description: 'Change event handler.' },
  { name: 'placeholder', type: 'string', description: 'Placeholder text shown when the textarea is empty.' },
  { name: 'disabled', type: 'boolean', default: 'false', description: 'Whether the textarea is disabled.' },
  { name: 'className', type: 'string', description: 'Additional CSS classes to apply.' },
]} />

The component also accepts all standard HTML `<textarea>` attributes (except `size`, which is replaced by the component's own `size` prop).
