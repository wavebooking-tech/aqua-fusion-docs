# Loader

A simple spinning indicator used to communicate that content is loading. Renders as a rotating border circle with configurable size and color.

## Import

```tsx
import { Loader } from '@wavebooking/aqua-fusion';
```

## Preview

<StorybookEmbed story="components-loader--default" height={150} />

## Usage

```tsx
<Loader />
```

### Sizes

```tsx
<Loader size="sm" />
<Loader size="default" />
<Loader size="lg" />
```

### Color variants

```tsx
<Loader variant="default" />
<Loader variant="white" />
<Loader variant="gray" />
```

### Inside a button

```tsx
<Button disabled>
  <Loader size="sm" variant="white" />
  Loading...
</Button>
```
